# ZažijVR Email – vydání

Podepsané instalační balíčky aplikace **ZažijVR E-mail & Kalendář**. Zdrojový kód je v soukromém repozitáři.

## Instalace (Linux)

```bash
curl -fsSL https://raw.githubusercontent.com/zazijvr/Zazij-VR-Email-releases/main/install-appimage.sh | bash
```

Aplikace se uloží do `~/Applications` a objeví se v nabídce jako „ZažijVR Email“.
Další verze si stahuje a instaluje sama; každá aktualizace je ověřená podpisem.
